# متن آماده برای «توضیحات بیشتر برای بررسی‌کننده» بازار

روشنو یک لانچر فارسی با رابط ساده و دکمه‌های درشت برای سالمندان و کاربرانی است که استفادهٔ آسان‌تر از گوشی را می‌خواهند. تماس، مخاطبین، پیامک و دوربین از قابلیت‌های اصلی برنامه هستند و دسترسی‌های زیر برای اجرای همین قابلیت‌ها استفاده می‌شوند:

۱. android.permission.CAMERA
برای پیش‌نمایش دوربین و عکس‌گرفتن در بخش «دوربین» داخل برنامه استفاده می‌شود. درخواست دسترسی با انتخاب دکمهٔ «اجازهٔ استفاده از دوربین» انجام می‌شود. عکس‌گرفتن فقط با زدن دکمهٔ مربوط انجام شده و تصاویر در فضای خصوصی برنامه روی گوشی ذخیره می‌شوند.

۲. android.permission.READ_CONTACTS
برای نمایش نام و شمارهٔ مخاطبین گوشی در بخش «مخاطبین»، جستجو و انتخاب شمارهٔ تماس استفاده می‌شود. برنامه برای نمایش همهٔ مخاطبین، به خواندن فهرست نیاز دارد. دسترسی هنگام انتخاب نمایش مخاطبین یا ذخیرهٔ مخاطب جدید درخواست می‌شود.

۳. android.permission.WRITE_CONTACTS
برای ثبت مخاطب جدید با نام و شماره‌ای است که کاربر در فرم داخلی برنامه وارد می‌کند. این دسترسی در مرحلهٔ ذخیره درخواست می‌شود. پس از اعطای دسترسی، کاربر باید دوباره دکمهٔ ذخیره را بزند. برنامه مخاطبین اصلی گوشی را به‌صورت خودکار ویرایش یا حذف نمی‌کند.

۴. android.permission.CALL_PHONE
برای شروع تماس سیم‌کارتی از شماره‌گیر داخلی و فهرست مخاطبین استفاده می‌شود. کاربر شماره یا مخاطب را انتخاب کرده و سپس شروع تماس را در پنجرهٔ تأیید جداگانه تأیید می‌کند. اعطای دسترسی به‌تنهایی تماس برقرار نمی‌کند. صفحهٔ حین تماس و قطع تماس توسط برنامهٔ تلفن گوشی مدیریت می‌شود. شماره‌های اضطراری به شماره‌گیر سیستم هدایت می‌شوند.

۵. android.permission.READ_SMS
برای نمایش فهرست گفت‌وگوها و متن پیامک‌های همین گوشی در بخش «پیام‌ها» و امکان پاسخ‌دادن استفاده می‌شود. درخواست دسترسی با انتخاب دکمهٔ اجازهٔ خواندن پیامک‌ها انجام می‌شود. برنامه پیامک‌ها را حذف نمی‌کند و وضعیت خوانده‌شدن آن‌ها را تغییر نمی‌دهد. مشاهدهٔ تغییرات پیامک‌ها به زمان فعال‌بودن صفحهٔ مربوط محدود است.

۶. android.permission.SEND_SMS
برای ارسال پیامک جدید یا پاسخ به پیامک از داخل برنامه استفاده می‌شود. شمارهٔ گیرنده و متن با اقدام کاربر تعیین شده و ارسال فقط پس از تأیید صریح در پنجرهٔ «این پیامک فرستاده شود؟» انجام می‌شود. هزینهٔ سیم‌کارت در رابط برنامه توضیح داده شده است. هیچ پیامکی به‌صورت تبلیغاتی یا خودکار ارسال نمی‌شود.

برنامه مجوز اینترنت، حساب کاربری، SDK تبلیغاتی یا ابزار تحلیل رفتار ندارد. مخاطبین، متن پیامک‌ها و تصاویر به سرور ارسال نمی‌شوند. دسترسی‌ها به‌صورت زمان اجرا و در جریان قابلیت مربوط درخواست می‌شوند؛ رد دسترسی باعث مسدودشدن سایر بخش‌های برنامه نمی‌شود. دکمهٔ «کمک می‌خواهم» برای دسترسی به فرد مورد اعتماد است و سرویس امدادی محسوب نمی‌شود.

## مسیرهای پیشنهادی بررسی

- دوربین: خانه ← دوربین ← اجازهٔ استفاده از دوربین ← عکس گرفتن.
- مخاطبین: خانه ← مخاطبین ← نمایش مخاطبین گوشی؛ برای ساخت: افزودن مخاطب جدید ← واردکردن نام و شماره ← ذخیرهٔ مخاطب ← اعطای اجازه ← ذخیرهٔ مخاطب.
- تماس: خانه ← تماس ← واردکردن شماره ← تماس با این شماره ← اعطای اجازه در صورت نیاز ← شروع تماس یا انصراف. تأیید تماس واقعی ممکن است هزینه داشته باشد.
- پیامک: خانه ← پیام‌ها ← اجازهٔ خواندن پیامک‌ها؛ برای ارسال: نوشتن پیام جدید ← شماره و متن ← بررسی و ارسال ← اعطای اجازه در صورت نیاز ← ارسال پیامک یا انصراف. تأیید ارسال واقعی ممکن است هزینه داشته باشد.

## نتیجهٔ بررسی کد

هر شش دسترسی در پیاده‌سازی فعلی برای قابلیت‌های صریحاً درخواستی استفاده می‌شوند؛ دسترسی بدون کاربردی در این فهرست یافت نشد. برای حفظ تماس، پیامک، دوربین و ایجاد/نمایش مخاطب داخل برنامه، Manifest در این کار تغییر نکرد. این یادداشت آمادهٔ درج در پیشخان است و به‌معنای ثبت آن در حساب بازار یا تأیید انتشار نیست.
